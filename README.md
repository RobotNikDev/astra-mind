# AstraMind

AstraMind — локальная система компьютерного зрения с голосовым описанием происходящего.

## Архитектура

Linux:
ORBBEC AstraPro - захват изображения 
local YOLO + local VLM - детекция объектов
local LLM - генерация текста

MacBook:
say - генерация и воспроизведение аудио
